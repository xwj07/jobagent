# 模拟面试：手写 Agent loop

工作台先解析简历，再在任意岗位卡片点击「开始模拟面试」。上传的 JD 与在线获取的 JD
使用相同入口。三个主题从中等难度开始，每个主题最多追问一次，共 3～6 次回答。
记录保存在数据库 `interview_sessions`，浏览器只保存最近一次面试 ID，刷新后恢复。
也可提前结束；仅已提交回答参与评估，未回答主题计 0 分并标明未回答。

## 语音与手写作答

默认选择「语音作答（推荐）」，用户可切换「手写输入」。点击开始录音才请求麦克风权限，
停止后可以试听、重录，点击提交才上传。浏览器将录音编码为单声道 PCM WAV；
后端把音频通过 chat completions 的 `input_audio` 直接交给 Gitee
`Qwen3.8-Omni-Flash`，一次调用返回回答文字、评分、追问建议。
没有调用浏览器语音识别或独立 ASR 接口。手写输入继续使用原有文本模型。

语音模型复用 `JOBAGENT_LLM_BASE_URL` 和 `JOBAGENT_LLM_API_KEY`，
通过 `JOBAGENT_AUDIO_MODEL` 配置，默认 `Qwen3.8-Omni-Flash`。
需要密钥具有对应模型的调用权限。录音仅在请求期间传给模型，不写入数据库；
数据库保存模型理解的回答文字、作答方式和实际评估模型，面试评分仍按原有四维规则计算。
语音记录中的文字是模型理解结果，需要用户自行核对其准确性。

麦克风页面需要 HTTPS 或 localhost。权限拒绝、无麦克风、设备占用、模型请求失败都会
显示具体原因，不会自动切换作答方式。录音或转换期间停止提交，避免把未完成录音发给模型。

## 一次循环

1. `plan_interview`：模型根据简历和 JD 制定三个主题，每个主题预先生成基础、进阶、挑战问题。
2. 提交回答后，程序调用唯一的评估工具 `assess_answer`，传入该主题的问题和全部回答。
3. observe：保存结构化评分、回答原文依据、优点、改进建议及追问建议。
4. reflect：根据模型建议和追问次数，程序决定追问或切换主题。追问沿用当前难度。
   切换主题时，加权分 >=80 提升一级，<40 降低一级，其余保持。难度仅有 1～3 级。
   追问之后一定切换主题。
5. 三个主题结束后，程序计算报告。每步 trace 和输入快照都保存在数据库状态内。

实现位于 `src/jobagent/interview.py`。这是手写、固定工具集合的循环，不使用 LangGraph，
也没有向模型开放任意工具调用。之后可以将 plan/assess/route/finish 映射到状态机节点，
再添加节点级 checkpoint、人工介入与执行回放；当前是每次成功回答后持久化整个会话。

## 评分

技术理解 40%、问题分析 30%、实践经验 20%、表达清晰度 10%。模型各维度输出 0～100，
Python 负责加权汇总。0=无有效信息，25=零散且关键错误，50=基本正确但缺关键细节，
75=正确具体且有理由，100=完整准确且解释边界与权衡。

每个主题以最后一次评估为准，该评估综合主问题与追问回答，避免同一主题重复计权。
三个主题等权。报告引用回答原文，包含改进建议和考察要点；面试中不返回评分与考察要点。
这是练习表现反馈，不是实际招聘决定。模型评分仍需人工评估其稳定性。

## 输入与权限

JD、简历、回答通过 user 消息作为 JSON 数据提供；任务与评分规则放在 system 消息。
回答中的指令不能修改系统任务。模型只返回证据对应的回答编号，程序核对编号后从原始回答
取前240字作为报告摘录；全文保留在对话记录中，不让模型生成或改写原文引用。
循环只允许计划和评分，不开放 shell、文件、网络或密钥读取工具。
这些边界不等于已经证明模型免疫所有提示注入，仍需进一步扩充攻击评估集。

## API

- `POST /interviews`：与 `/matches` 相同输入 `{resume, job}`。
- `GET /interviews/{id}`：恢复公开会话视图。
- `POST /interviews/{id}/answers`：`{"answer":"回答"}`，返回下一问题或最终报告。
- `POST /interviews/{id}/audio`：multipart `file` 为 WAV，直接进行音频理解与评估。
- `POST /interviews/{id}/finish`：提前结束，汇总已提交内容。

测试：`python -m pytest tests/test_interview.py`。覆盖追问上限、难度切换、主题累计评分、
早停、私有考察点、原文证据、输入消息隔离、保存恢复与结束后禁止继续答题。
`node tests/test_voice.mjs` 验证 WAV 编码、录音生命周期、方式切换和麦克风权限错误，
不访问真实麦克风。
